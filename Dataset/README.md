# Dataset

Upload the CSV files used in this project to this folder so that reviewers can access the data alongside the SQL scripts and Power BI dashboard.

## Expected files

- `accounts.csv`
- `subscriptions.csv`
- `feature_usage.csv`
- `support_tickets.csv`
- `churn_events.csv`

These are the five datasets used for the RavenStack SaaS Subscription & Churn Analytics project. Keep the original column names consistent with the SQL scripts, and update this file if you rename or replace any dataset.

## Uploading the files

1. Open this `Dataset/` folder in the repository.
2. Select **Add file → Upload files**.
3. Upload the CSV files and commit the changes.

**Data note:** Only upload data you are permitted to share publicly. This project uses synthetic portfolio data; do not upload real customer information, credentials, or other sensitive data. GitHub's browser upload limit is 25 MiB per file. If a dataset exceeds that limit, use Git from the command line or an appropriate large-file storage option.
